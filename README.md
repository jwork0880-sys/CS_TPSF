This repository is for reproducing analyses in the paper: "Biogeochemical links between contemporary litter decomposition and peat formation in a tropical peatland." By Ren et al. The main data file provided in this repository will be sufficient to conduct the main data analyses presented in the paper using RStudio.
Note that the code was developed with support of generative AI (Claude).\
